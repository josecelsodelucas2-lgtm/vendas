# 🛒 VendaFácil PDV - Sistema de Vendas

Aplicação web de Ponto de Venda (PDV) e controlo de inventário, desenvolvida com HTML, Tailwind CSS e JavaScript.

> 🚀 **Aceder à aplicação:** [https://josecelsodelucas2-lgtm.github.io/vendas/](https://josecelsodelucas2-lgtm.github.io/vendas/)

---

## 📌 Funcionalidades

- **Frente de Caixa (PDV):**
  - Catálogo de artigos com pesquisa instantânea e filtros por categoria.
  - Carrinho de compras dinâmico com cálculo de descontos e totais.
  - Métodos de pagamento: PIX, Cartão e Dinheiro (com cálculo automático de troco).

- **Impressão de Recibo:**
  - Formatação específica para impressoras térmicas (80mm) pronta para impressão.

- **Gestão de Stock & Artigos:**
  - Adição e atualização de artigos com controlo de quantidade.
  - Notificação de artigos esgotados.

- **Dashboard & Relatórios:**
  - Faturação total, contagem de vendas, ticket médio e produto mais vendido.
  - Histórico detalhado de transações com possibilidade de reimpressão e exportação para **CSV**.

- **Persistência de Dados:**
  - Todos os dados ficam armazenados localmente no browser via `localStorage`.
